# Quote Request Standards

Owner: Procurement / vCIO · Effective: 2026-10-01 · Used by: Split Request Classifier

> **Example standard.** Replace the values with your own before you upload this to Knowledge. Keep the headings — the agent searches by them.

## What counts as a purchase

A quote request is raised only for things that have to be bought. These rules override the classifier's general judgement:

| Situation | Quote? |
|---|---|
| New workstation, laptop, tablet, desk phone or mobile device | Yes |
| Monitors, docks, headsets, keyboards, mice | Yes, unless the request says they come from stock |
| Microsoft 365 licence | Only when the client has no free seat of that licence |
| Other software licences (Adobe, AutoCAD, etc.) | Yes — we bill licences separately |
| Re-using, reassigning or collecting existing equipment | No |
| Printer access, VPN access, group or mailbox access | No |
| Warranty extension or support renewal | Yes |

## Quote request summary format

Pattern: `Quote - {item summary} - {first last or site} - Needed by {date}`

Example: `Quote - Laptop + Adobe Acrobat - Dana Reyes - Needed by 14 Oct`

Keep it under 100 characters. Summarise the items in two or three words; the full list goes in the description. If there's no needed-by date, leave that part out.

## Quote request description layout

Write it in this order:

1. **Needed for** — who the purchase is for and why, in one sentence.
2. **Needed by** — the start or needed-by date. Hardware lead time is usually 5–7 business days, so say so when the date is closer than that.
3. **Line items** — one line per item: item, quantity, standard catalog item (if it matches), and notes.
4. **Approver** — who can approve the spend, if the request names one.
5. **Deliver to** — office location or address, if given.
6. **Linked service ticket** — added automatically by the workflow.

## Required information before quoting

A quote can still be raised when something is missing, but the missing items must be listed so the account manager can chase them:

- Quantity for every item (assume 1 only for items that are clearly per-person, like a laptop for a new starter).
- Needed-by date.
- Delivery location for hardware.
- An approver when the request is for more than one device or includes any item marked "Needs approval" in the Standard Catalog.

## What never goes on a quote request

- Prices, discounts or margins — the account manager prices it.
- Part numbers, vendor SKUs or a chosen supplier, unless the Standard Catalog names a preferred one.
- Items the requester didn't ask for, even if they're usually bundled.
