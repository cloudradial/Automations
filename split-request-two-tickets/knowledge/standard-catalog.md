# Standard Catalog — Hardware and Software

Owner: vCIO · Effective: 2026-10-01 · Used by: Split Request Classifier (and, later, Endpoint LifeCycle Manager)

> **Example catalog.** The items below match the choices on the stock *Add a New User* form. Replace them with the models and licences you actually sell before uploading. Keep the headings — the agent searches by them.

## How to match a request to the catalog

- Match a requested item to a catalog item only when it's clearly the same kind of thing ("a Mac", "MacBook" → MacBook Pro). Write the catalog item's name exactly as listed.
- If the request is vague ("a computer"), use the role default below and say so in the notes.
- If nothing in the catalog fits, keep the requester's own words and mark the line **non-standard**. Never invent a model, spec or SKU.
- Items marked **Needs approval** need a named approver on the quote.
